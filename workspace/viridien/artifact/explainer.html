One row per interval, touching with no gaps. Pixel rows use the same coordinates as the bounding boxes. Depth is linear here: 20 px per foot.

Every log goes through four steps

1. Splitfind each interval's top and bottom row
2. Groupsame pattern, same cluster id
3. Namematch each cluster to a legend swatch
4. Depthread the depth column, fit row to feet

The inputs: three boxes per page

Every annotation gives three rectangles: red is the depth column, blue the interpreted lithology column, orange the legend. Layouts differ a lot between companies.

Making the datasets: how good are AI labellers?

Only one true answer ships with the challenge, so agents label more windows. Each labeller also labels log06, where we know the truth, which tells us how far to trust its other labels.
