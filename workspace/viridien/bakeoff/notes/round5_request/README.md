# Round 5 modern ZIP pilot

Use this optional list to request modern Gulf mud-log packages from BSEE.
It has 20 files from 20 API10 well groups. The listed total is 1,013,092,659 bytes
(1.013 GB). All records have a run date in 2005 or later and water depth
above 1,000 ft. All have a current release date. The file type is Mudlog ZIP.

The rank uses Gulf area, date, water depth and size as metadata proxies.
No image match score is claimed. ZIP members and layouts remain unknown.
Known challenge well roots were removed. Unknown aliases can remain.
After download, check original names and hashes before admitting any page.

Upload modern_zip_filename_ids.txt to BSEE Well Data after Login.gov sign-in.
It contains exact DOC_ID values, one per line, without extensions. Check the
returned API, lease, suffix and size against modern_zip_pilot.csv. Add the
selected records to a Custom Set, then Request Cart. The owner must review
and submit. No account or request was used by the agent.

The public FRS limit is 25 GB per request. Preparation can take 24 hours.
The published download link lasts five days after activation. Signup and
authenticated controls were not tested. The detailed owner guide is at
external_untrusted/round5/r5_bsee_nologin/OWNER_ACTION_GUIDE.md.

This is a new ZIP pilot. The earlier 60-TIFF pilot remains in
bakeoff/notes/bsee_list/pilot_request.csv. Neither list confirms image layout.

Source: https://www.data.bsee.gov/Other/Files/FRSWellDataRawData.zip
The filtered source and its hash are recorded in checks.json. The original
source rows are retained in modern_zip_pilot.csv. No new web request was made.
