What the 51 logs are made of, and which legend entries look alike

Shares come from the colour estimator over every row of all 51 columns (the label mix page). Rows whose colour fits two legend entries are split evenly between them ("with ambiguous"). Rows the colour cannot name are listed separately below the table.

1. Rock categories across all logs

Listed in = how many legends include it. Rows = share of all filled column rows (big Gulf logs dominate). Per log = average share when every log counts the same. Per type = average when every legend type (Gulf, Texas, D-582 ...) counts the same.

2. Look-alike pairs inside the same legend

Only entries of the SAME legend compete when a log is labelled, so these are the pairs that matter. Rows at stake = column rows whose colour fits both. The classifier cuts every 48-row window of every column, drops windows holding two beds, a white gap or text, and matches the rest against that log's whole legend (native-size swatches: colour, mark shape and direction, template match). Each card shows windows it called A or B. Tap a window that is called wrong. Dashed = weak call.
