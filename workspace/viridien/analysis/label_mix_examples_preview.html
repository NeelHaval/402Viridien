What the 51 lithology columns are made of, and how hard each legend is

Each row of each column has its fill colour matched to that log's own legend swatches. These are estimates only: the one true answer is log06 (the organisers' example CSV).

Read with care. The shares come from a colour estimator, not from labels. It cannot read hatch patterns, it ignores grey fills (see the parsed Gulf example), and its legend reading is automatic (the parser now reads all 51 legends; 11 were fixed on 7 Nov). Use it to rank difficulty, not as accuracy.

Difficulty per legend family

Score 0-100 = 40% rows only a pattern can name (all of them on 1-bit scans) + 20% ambiguous colour + 10% colour not in legend + 10% many rock types + 8% busy column + 6% tiny swatches + 6% narrow column. Higher is harder.

With every legend parsed, the biggest bucket is colour that fits two or more swatches: a colour-only reader cannot name over a third of the column, and a fifth matches no swatch. Pattern reading (or a vision model) is needed for both.

Shale is the largest named rock at about 10%, and every other named rock is under 3%. So a strategy that only gets Shale right can still look decent on row accuracy.

Rows to read = one row signature every stride (finds boundaries) + 2 x 20 full-resolution rows around each boundary + naming patches. Per-interval naming reads one patch per interval and needs one vision call per interval. Per-cluster naming groups similar intervals and names each group once from 3 patches (12 groups per log), so its vision-call count is fixed by the number of logs. Total filled rows: 3.09 million.

Reading the table. The Gulf 3-panel type is 59% of all filled rows, so it alone sets most of the score: it needs about 90% row accuracy, and half of its column is ambiguous by colour alone. Texas is 19% and easy, so it is held to the strictest target. D-582 and MC761 are tiny (under 2%), so even 82-88% there costs little overall. Where beds are thinner than a naming patch (marked thin), every row must be read at full resolution and patches overlap neighbouring beds: these are the logs where accuracy will be hardest to buy.

Accuracy targets split a 10% overall error budget across types in proportion to their difficulty score, weighted by volume. They are a planning tool, not a promise. Bed heights come from only 1-52 labelled beds per type (Geoservices: 1), so treat those columns as rough.
