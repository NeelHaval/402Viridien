  1. Choose a document, then choose a pattern in its legend.
  2. Select a segment. Drag its top, bottom, or side edges. Use Draw box for a new selection.
  3. Choose the correct legend labels, then select Accept segment.

  5. Open Pattern lab to compare the real pattern with a generated sample. Export the dataset when the examples are correct.
