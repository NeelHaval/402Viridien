## Run and improve the classifier

```sh
python scripts/datasets.py fetch crops --destination data/local/pr54
python -m viridian402 classify --data-root data/local/pr54 --model builtin:prototype --output runs/crops
python -m viridian402 classify --data-root data/local/pr54 --model my_package.crop_model:predict --config configs/crop-model.json --output runs/crops
python -m viridian402 report runs/crops/RUN_ID
python -m viridian402 compare runs/crops/BASELINE_ID runs/crops/CANDIDATE_ID
python -m viridian402 runs --output runs/crops
```

The workflow suite is **real-crops**. Its default `builtin:baseline` UI selection automatically resolves to `builtin:prototype` for this task; choose a custom classifier function explicitly when replacing it. The input mode switch concerns interval evaluation and does not grant crop truth. `--min-score`/the workflow minimum gate means exact-set accuracy for this suite.

Custom crop models implement:

```python
def predict(request: dict, config: dict) -> list[str]:
    # request['crop']: authoritative native PNG path
    # request['candidate_labels']: vocabulary learned from eligible train records
    # no sample/document/group identifier or expected targets in the request

```

Fit custom models separately on `train.jsonl`, then point a tracked config at the resulting checkpoint. Declare its `training_groups` from the source policy. Target keys are exact; the evaluator does not silently merge rock categories. Classes occurring only in test remain in the metric denominator. A multi-label crop's targets do not reveal where its components are, so no proportions, bed thickness, boundaries or depths are inferred.

The prototype baseline fits inexpensive RGB/texture class centroids on eligible training pixels only. It intentionally provides a simple reproducible starting point. Per-crop isolated workers enforce hard timeouts and strip credentials. Output includes a trained prototype artifact, per-case predictions/errors, exact-set accuracy, micro/macro F1, per-class/per-well/prior-exposure results, timings/RSS, source and package hashes, integrity checks and a readable summary. Comparisons require matching audited data, metric implementation and case metadata. Failed/empty predictions remain in denominators and fail execution checks.

## Initial execution evidence

The verified prototype run completed **112/112** test crops with no errors or empty predictions. Exact-set accuracy was **8.93%**, prospective-status accuracy **13.33%** (60 cases), retrospective **3.85%** (52 cases), and macro F1 **0.0913**. This is a weak baseline, not a model-quality claim. These figures measure crop classification and cannot be compared to the interval score.

The source PR explicitly records its inherited generator suite as **12 failed, 169 passed, 2 skipped, 8 errors**. Its generation reviews identify rails, seams, missing classes, pattern-box height used as bed thickness, and exact-pixel quarantine bypasses. This repository's small deterministic interval construction tests are separate. Do not use source experimental synthetic results as headline real-world accuracy or automatically promote its saved model artifacts.
