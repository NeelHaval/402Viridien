The train-only prototype fit used 907 eligible crops and excluded 9 quality holds. It completed 112/112 test crops: exact-set accuracy **8.93%**, macro F1 **0.091**, sampled peak worker RSS **45.0 MiB**. Coordinator wall time including training/audit work after initial audit was 77.8 seconds. This measures crop names, not interval boundaries or depths.

Six exact target keys are absent from the training vocabulary and affect 33/112 test crops: `coarsesandstone`, `limestonel`, `othersh`, `sandyclayshale`, `siltyclayshale`, `slatyshale`. The closed-vocabulary prototype cannot predict these. They remain in the denominator. Do not silently merge categories to improve a score; review the taxonomy and label provenance first.

## Whole-scan operational stress

The unlabelled full-page baseline completed **31/48** scans under a 30-second timeout and sampled 1,536-MiB worker ceiling. Seven failed the 12-million-crop-pixel budget; ten would require a 549-1,066 MB native Pillow TIFF decode above the 512 MB reader budget. None was silently omitted. The report/gates fail as intended. No supervised accuracy is assigned. Smaller windows, supported strip codecs or pre-tiling are needed before claiming full-scan support. Raising limits alone is not a robustness fix.

## Reproduce and interpret

```sh
python scripts/benchmark.py --model builtin:baseline --model builtin:legacy-s11 --suite human --suite organizer --suite external-dev --suite external-diagnostic
python -m viridian402 classify --data-root data/local/pr54 --output runs/crops
python scripts/benchmark.py --suite challenge-unlabelled --timeout 30 --max-worker-rss-mb 1536
```

Fetch the pinned evaluation/crop/challenge bundles and install the documented model dependencies first. The last command deliberately returns a failed gate for unsupported full-scan cases. JSON values, fingerprints and run IDs are in [2026-11-08.json](2026-11-08.json). Complete run artifacts include per-case failures, predictions, class/group results and package/source hashes.

Pixel accuracy is pooled by labelled row count; boundary F1/composite are means over cases. The composite is row accuracy multiplied by boundary F1 per case. Sources have different distributions and prior exposure, so no combined headline accuracy is claimed. Shared external diagnostic data were tuned previously. Prospective crop status is inherited metadata, not a new blinded evaluation.

Worker timings include startup, model loading and inference; parent validation, hashing, scoring and previews are reported separately. RSS is sampled over worker descendants. Local shared-machine timings are descriptive, not controlled speed benchmarks. Depth OCR was skipped in these S11 runs, so depth MAE is unavailable and missing-depth rate is 100%.
